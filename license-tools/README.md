# License tools (vendor only)

- `license-generator.html` is the browser generator. Open it locally, load your signing key and issue, check or renew licenses.
- `generate.php` is the command-line generator (`issue`, `inspect`, `keygen`).

Full guide: [../docs/LICENSING.md](../docs/LICENSING.md)

This folder is **excluded from the cPanel upload ZIP** and blocked from web access.
**Never** put your `cityland-license-signing-key.json` in this repository or on any server.
